# 人与 AI 扩展流程：增加一篇正式论文

本流程对应 v2 本地研究示例。当前可用入口与完整字段见 `docs/paper-agent-data-model.md`；工具只读，新增材料由具备项目写权限的人或编码代理按步骤写入受控目录。自动查找、下载或发现证明词汇都只产生候选证据。

## 先确定范围和材料

1. 确认用户要求的论文与处理范围。用户仅授权选定结果示例时，不扩大成整篇重写，不编造整篇完成率。正式待收录表的整体确认与某几篇 demo 授权可以不同。
2. 只选可核实会议/期刊正式全文及其正式补充材料。记录出版页 URL、正式 PDF URL、原文首页身份、页数、SHA-256。arXiv 可作发现线索，不能替代本轮正式原文或沿用另一版本的页码计数。
3. 给论文、版本、源文件分别建立稳定 ID。相同 SHA-256 的重复文件保持一个源实体；同一论文的更新文件建立新版本，保留旧版本。不同论文引用同一数学结果仍是不同论文实体。
4. 手动私稿默认 `unpublished/private`，只在本地处理；没有用户授权，不发送到网页检索、外部解析或其他服务，也不把派生记录放入 public package。本 demo 的公开目录只含三篇已授权正式论文。

## 核对出现记录和命题

5. 阅读选定原文，保存原陈述、定义、条件、证明位置和公式转录；明确 PDF 页码从 1 开始。标记作者在本篇自证、外引未给证明、外引同时重证，或证明子结论。文字抽取只用于定位，必须与 PDF 数学式对照。
6. 分别登记主文陈述与附录重述的 `occurrences`。用 `repeats_statement` 保留出现记录；不会把重述算成新的独立命题。原文定理有多个子结论时建立 `theorem_component` 或带明确 clause 的结果，不增加原定理编号。
7. 规范命题之前逐项对齐量词、类型、有限变量域、空集、基线、归一化、函数定义、精确等号与近似号。相似词汇仅建 `candidate` 关系；对齐完成后才使用 `instantiates` 或明确的等价关系。
8. 先查公共库与已有共享证明。一般性公共命题更强时，为论文编写真实实例化适配，保留定义映射和实际代码；不要复制共享证明到每篇论文并宣称是多份独立证明。本文三篇重构实例共用一份公共证明，中心化差异在 F03 适配里处理。

## 原文疑点与修改授权

9. 疑似数学错误先排除 OCR/转录失真，再登记原位置、原陈述、问题、反例或推导、影响范围。`user_confirmation: pending` 与 `fix_authorization: pending` 分别保持待定；技术判断不等于用户确认。
10. 暂停受影响原命题的数学修改，继续不依赖它的工作。用户确认问题后才讨论具体改法；明确授权改法后另建修正记录和版本，保留原式。不能先补条件、改结论或发布替代证明，然后把新编译结果充当原文通过。
11. 父定理待对齐不自动阻塞一个已经独立对齐的正确子结论；子结论通过也不能提升父定理。F11 的 AND 子结论与全部 AND/OR 定理示例体现这个范围区别。未经问题确认的独立 OR 实验不出现在公开可用 API。

## 重写、形式化和证据

12. 可读证明要完整解释定义、证明主线、每步公式、所用引理、条件在哪里使用和一个小例子。为步骤建立稳定 ID 与 `lean_refs`，保存共享证明引用和论文适配的区别。原文公式与项目新写证明分别标识。
13. 在独立论文适配文件中实现选定结果。复用公共库，以明确有限域限制所有子集；基线是否中心化要与正式定义一致。具体 mask 实现未证明时明确该边界。
14. 从项目根目录加载 `scripts/env.sh`，使用已锁定 Lean/mathlib 和现有 Conda 环境；不修改系统配置，不需要联网安装大批依赖。执行适当编译与传递公理审计，生成真实报告。
15. 报告记录命令参数、cwd、退出码、日志、声明签名、源码位置、依赖、公理、工具链、依赖锁、所有输入源码哈希和统一源指纹。公理字段未知必须标未知，不能默认空列表。公共库报告与论文适配报告的证据范围分开。

## 接入本地示例并验收

16. 更新 `data/papers.json`、来源 excerpt、`data/math-content.json` 与 graph 中相关实体/边。生产迁移由另一轮明确的工程任务实施；不要直接改 corpus 原件或 production schemas。当前 `build_package.py` 固定三篇示例，扩展实际论文时应在确认的新范围中更新其白名单与映射，而不是以新 ID 冒充旧论文。
17. 运行 schema 结构验证和语义验证，检查所有外键、证明存在、来源版本、哈希、页码、可见性、适配范围、父子结果状态、重复出现和报告新鲜度。使用的 schema 关键词超出受限验证器支持范围时升级验证器或采用标准实现，不能静默忽略。
18. 检查公开工具、页面和资源白名单。确认 query 每个结果只返回一次；重复主文/附录出现可见但不增加完成结果数；私有论文、派生记录、链接、路径和实验 OR 内容不出现在 public 查询中。
19. 保存真实验证命令与退出码。只把当前报告覆盖的声明标为编译通过；代理语义审阅、用户审核、完整重写、数学问题与修正授权仍独立记录。例子级通过不表示全文结论已验证。

## 真实可调用入口

```bash
source scripts/env.sh
python research/reader-v2-20260930/architecture/paper_agent.py validate
python research/reader-v2-20260930/architecture/paper_agent.py invoke query '{"text":"重构"}'
python research/reader-v2-20260930/architecture/paper_agent.py invoke get-result '{"identity":"iclr2024-sparse-reconstruction"}'
python research/reader-v2-20260930/architecture/paper_agent.py invoke dependencies '{"identity":"cvpr2023-uniqueness","depth":3}'
python research/reader-v2-20260930/architecture/paper_agent.py invoke verification-status '{"identity":"iclr2024-generalizable-andor"}'
```

参数只接受注册工具的封闭 JSON schema；不接受 shell、任意路径、网络 URL 或写操作。上述是本地 CLI 调用，不是 MCP 连接。流程文档已作为 `prompts[]` 注册，远程服务、MCP transport 与自然语言代理仍待独立实现。
