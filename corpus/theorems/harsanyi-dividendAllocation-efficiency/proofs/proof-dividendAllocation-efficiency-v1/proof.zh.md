# 总归因等于去基线的总值

命题：\(\sum_{i\in N}\phi_i(v;N)=v(N)-v(\varnothing)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：交换有限的变量求和与子集求和。

<a id="step-1"></a>

1. 交换有限的变量求和与子集求和。

<a id="step-2"></a>

2. 每个非空 S 的等分份额之和由上一结论等于 I_v(S)；空集没有成员，贡献为 0。

<a id="step-3"></a>

3. 所以总和等于所有子集交互之和减去 I_v(∅)。

<a id="step-4"></a>

4. 重构定理与空集交互分别给出 v(N) 和 v(∅)。允许 N=∅，此时两边都是 0。尚未形式证明经典阶乘边际公式的等价性。
