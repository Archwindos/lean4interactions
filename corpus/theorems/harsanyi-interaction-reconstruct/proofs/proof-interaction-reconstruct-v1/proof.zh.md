# 子集和的交互恢复原系数

命题：\(I_{R_d}(S)=d(S),\quad R_d(S)=\sum_{T\subseteq S}d(T)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：对 S 作插入归纳，空集情形直接计算。

<a id="step-1"></a>

1. 对 S 作插入归纳，空集情形直接计算。

<a id="step-2"></a>

2. 若 i∉S，则对任意 T⊆S，R_d(T∪{i})−R_d(T)=∑_(U⊆T)d(U∪{i})；两组中不含 i 的项抵消。

<a id="step-3"></a>

3. 因此 R_d 的插入差分，在 S 的每个子集上等于新系数函数 U↦d(U∪{i}) 的重构。

<a id="step-4"></a>

4. 使用局部一致性和归纳假设，得到其在 S 上的交互为 d(S∪{i})。

Lean 关键声明：`Harsanyi.interaction_reconstruct`。各步骤解释同一声明的证明；类型转换和求和重写属于形式化辅助操作。
