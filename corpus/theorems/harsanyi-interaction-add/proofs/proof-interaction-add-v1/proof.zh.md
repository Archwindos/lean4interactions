# 交互的可加性

命题：\(I_{v+w}(S)=I_v(S)+I_w(S)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：展开交互定义，把每个系数乘以 v(T)+w(T)。
