# 等分交互归因保持中心化

命题：\(\phi_i(v^\circ;N)=\phi_i(v;N)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：归因求和中的有效项满足 i∈S，故 S 非空。

<a id="step-1"></a>

1. 归因求和中的有效项满足 i∈S，故 S 非空。

<a id="step-2"></a>

2. 对这些项，中心化不改变交互；其他项两边都是零。

<a id="step-3"></a>

3. 逐项相等推出总和相等。空集基线未分配给任何变量。
