# 等分交互归因的可加性

命题：\(\phi_i(v+w;N)=\phi_i(v;N)+\phi_i(w;N)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：逐个 S⊆N 展开等分交互归因。若 i∉S，两侧该项均为零。

<a id="step-1"></a>

1. 逐个 S⊆N 展开等分交互归因。若 i∉S，两侧该项均为零。

<a id="step-2"></a>

2. 若 i∈S，交互可加性给出分子之和；实数除法保持分子加法。

<a id="step-3"></a>

3. 对所有 S 求和得到归因可加性。此处使用的是 dividendAllocation 定义，尚未形式证明其与阶乘权重公式等价。

Lean 关键声明：`Harsanyi.dividendAllocation_add`。各步骤解释同一声明的证明；类型转换和求和重写属于形式化辅助操作。
