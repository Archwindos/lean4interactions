# 非空交互不受中心化影响

命题：\(S\ne\varnothing\Longrightarrow I_{v^\circ}(S)=I_v(S)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。；S.Nonempty（等价于 S≠∅）。

证明思路：中心化公式仅在空集处减去基线。

<a id="step-1"></a>

1. 中心化公式仅在空集处减去基线。

<a id="step-2"></a>

2. S 非空使对应指示函数为 0，因而交互保持不变。非空前提不能删除。
