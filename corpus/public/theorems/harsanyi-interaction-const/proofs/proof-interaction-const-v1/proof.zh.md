# 常数只贡献空集交互

命题：\(I_c(S)=\begin{cases}c&S=\varnothing\\0&S\ne\varnothing\end{cases}\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。；c∈ℝ。

证明思路：若 S=∅，空集交互给出 c。

<a id="step-1"></a>

1. 若 S=∅，空集交互给出 c。

<a id="step-2"></a>

2. 若 S 非空，将其写成 S₀∪{i} 且 i∉S₀。常数函数的插入差分处处为 c−c=0。

<a id="step-3"></a>

3. 增加变量公式与零函数交互给出非空集合上的交互为 0。
