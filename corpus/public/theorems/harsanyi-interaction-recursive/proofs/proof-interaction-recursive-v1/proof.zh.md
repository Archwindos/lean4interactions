# 从较小集合交互递推

命题：\(I_v(S)=v(S)-\sum_{T\subsetneq S}I_v(T)\)。

前提：变量类型 α 的相等关系可判定；S、T、N 为有限子集。；v、w、d 为实值集合函数，不默认 v(∅)=0。

证明思路：重构定理的子集和中，S 本身恰出现一次。

<a id="step-1"></a>

1. 重构定理的子集和中，S 本身恰出现一次。

<a id="step-2"></a>

2. 用 powerset.erase S 分离这一项，剩余指标精确对应严格子集。

<a id="step-3"></a>

3. 把其余交互总和移到右边。即使 S=∅，剩余和为空，仍得到 I_v(∅)=v(∅)。

Lean 关键声明：`Harsanyi.interaction_recursive`。各步骤解释同一声明的证明；类型转换和求和重写属于形式化辅助操作。
