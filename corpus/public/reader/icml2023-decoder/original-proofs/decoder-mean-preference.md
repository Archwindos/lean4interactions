If the expectation $\mu_l$ of convolutional weights in each $l$-th layer has a large absolute value $|\mu_l|$, then the decoder network is less likely to learn high-frequency components. It is because according to Theorem 4.2, a large absolute value $|\mu_l|$ boosts the imbalance effects $|\mu_lR_{uv}|^2$ among different frequency components, thereby strengthening the trend of encoding low-frequency components of the input sample.
