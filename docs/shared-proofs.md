# 共享证明的核对与维护

theorem_id 表示规范化命题，proof_id 表示证明方法或版本，claim_id 表示论文某次出现。相同命题不自动意味着相同证明；使用同一引理也不自动意味着可以合并主证明。

| 关系 | 必须核对 | 维护方式 |
| --- | --- | --- |
| 相同命题、相同证明 | 定义、全部假设、结论、推导一致 | 共用 theorem/proof，分别保留 claim |
| 相同命题、不同证明 | 假设与结论一致 | 共用 theorem，保留多个 proof |
| 经定义转换等价 | 转换方向、前提、基线及空集 | 独立转换说明与连接引理 |
| 特例或直接推论 | 实例化参数与前提满足 | 保留应用 claim/声明 |
| 部分中间论证相同 | 共用步骤的完整数学边界 | 提炼辅助引理，主证明分开 |
| 疑似相同 | 尚不足以核对 | candidate，保留独立记录 |

先用 search-lemmas 查询公共库，再读准确签名与权威陈述。relations.yaml 的关系须记录 from_id、to_id、relation_type、review_status、evidence、visibility；证据要说明数学核对，不能只有相似度或文字匹配。

公共内容只维护一份。原文 claim 保留符号映射、论文假设和 adaptation.zh.md；中文公共证明不重复复制到每篇论文。网页 theorem/proof 反向显示来源，claim 向公共结果链接。来源缺失假设或有错时先登记 issue，不能用正确公共库覆盖原文问题。

公共内容修改后执行 scripts/archive impact <id>，核对所有依赖与论文应用，再运行 Lean 审计和索引构建。旧来源、旧证明版本和报告继续保留。未发表来源的边及私有衍生证明继承 private；公共定理本身能保持公开，不代表其所有来源都可以公开。

当前是否已有经过核对的真实跨论文案例，以 STATUS 和 relations 的 evidence 为准。页面与合成测试的双向链接不计为数学共享案例。
