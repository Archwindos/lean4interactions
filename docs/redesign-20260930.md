## 3. TeX 来源真实性与排版必须同时解决

`original.tex` 扩展名不能证明内容来自作者 TeX。投诉条目和多数自动候选的文件实际是 PDF 提取纯文本，例如 `2n`、`xS` 和多行断开的求和。上下标、量词边界、列顺序和连字可能失真。取消转义不会恢复这些结构，也不能由 AI 自动补回后声称是精准原文。

当前 `archive-math.js` 对整段 `pre.math-source` 调用一次 `katex.render`。KaTeX 适合数学公式，不能完整编译混有英文段落、`theorem`、`small` 以及其他文档级命令的 LaTeX 环境；纯 PDF 文本则通常没有数学分隔符可渲染。生产模板对文本所做的 HTML 安全处理仍须保留，本轮没有发现原文面板把原文先做 JSON 序列化的代码。用户不应看到 JSON 引号和双转义字符串，也不应看到有关内部 HTML 安全处理的警告。

正式来源读模型应至少区分：

| 来源形式 | 给读者的文案 | 展示方法 |
| --- | --- | --- |
| 作者 TeX | 作者 TeX 原文 | 按已核对环境和宏上下文定位；默认阅读排版，随时查看与复制原样源码 |
| PDF 自动文本 | PDF 提取文本，尚未核对 | 保留文本和 PDF 页码；不把失真的字符当作可靠 TeX |
| 无源码但经 PDF 核对的转录 | 经 PDF 核对的公式转录 | 单独保留转录与核对证据，原 PDF 可返回；不命名为作者原 TeX |
| 尚无原文 | 原文尚未提取 | 返回材料与位置，说明缺少哪一部分 |

原命题与原证明分别有来源边界，不能拿一个自动截断的大块同时冒充两者。当前正式版演示的权威原文是 CVPR 正文第 3–4 页与 supplement 第 2–3 页。辅助排版对照旧 `AOG.tex:205–215`、`appendix.tex:116–129`、`appendix.tex:131–186`，只确认这些片段的数学内容，不声称完整文档一致。CVPR 正文的 Harsanyi/Shapley 文献编号分别为 [15]/[31]，辅助 arXiv 为 [29]/[56]；supplement 重构公式号为 (2)，arXiv 为 (10)。辅助复制逐字保留旧源码，不能改号后称作者原源码。

尚未完成 Theorem 2 的正式陈述位于正文第 4 页，辅助排版来自 `AOG.tex:261–265`；原证明入口指向正式 supplement 第 6 页起，不沿用 arXiv PDF 第 19 页。原证明全边界仍未核对，没有中文重写。

原型的排版器只移除版式命令，处理已知引用并分别渲染数学环境。它没有实现全文 TeX 编译、全局宏展开、交叉引用索引或公式转录。原样 TeX 模式和复制内容读取同一个未改写字符串；使用文本节点与 `trust: false`，不会把原文当作可执行 HTML。已有辅助 TeX 是公式阅读视图的依据，正式 PDF 原页可直接展开。它不是正式作者 TeX，不能将此效果直接推广给只有 PDF 的其他论文；没有可对应源码时应另存经正式 PDF 核对的转录。

## 4. 阅读信息架构

后续只收录正式会议/期刊版，原文定位、附件范围与证明计数均按该正式版本记录；arXiv 只可作为明确标注来源的辅助材料，不代替正式主版本。

正式主线为：**选论文 → 章节/原定理编号 → 原命题、原证明、中文重写、Lean 结果**。

论文页显示标题、作者、固定版本、实际附件、已核对的范围和未完成范围。阅读目录区分已重写证明、待核对定理与其他来源记录。一个命题的正文、附录重述与 TeX 出现保留多个出处，但通过同一阅读入口进入；跨来源合并须有核对记录，不能按编号或关键词自动认定相同。

已重写页默认显示中文证明全文，可读的假设和统一命题在前，分步证明在后。原命题、原证明和 Lean 结果是同页的并列选项卡。共享证明权威内容仍存放在原 `proof.zh.md`，页面引用它，不为每篇论文维护另一份副本。转换说明和公共库复用折叠在证明正文之后；需要理解某一步时，可以展开真实已有依赖引理。

数学读者主文应保留实际数学对象、假设和边界，避免不必要的 Lean 实现条件，例如 `DecidableEq` 应放在 Lean 栏解释。当前原型在显示层将“变量类型 α 的相等关系可判定”移到 Lean 栏的“编码约定”折叠区，数学正文保留有限集合、实值函数、空集基线等原有条件。权威短证明与假设字段逐字不改，原文下载保持原样。正式内容审校应把数学假设与实现条件分开，不能由前端擅自省去实质前提。

未完成页先用一句“尚未重写”说明事实，然后展示已有原文和原证明位置。原文边界未核对、未完成命题对齐、未完成 Lean 分别在进度页说明。没有正文时不显示空的“中文证明”“共享结果”“定义转换”大区块；缺失仍保留在清单和进度统计里。

正文引用或自动误报进入来源记录，提供原位置和已识别的被引用定理入口。它不是数学错误。实际数学疑点另有简短、具体的提醒：哪一页、哪一个量词或步骤、什么核验依据、影响哪些命题。通用“用户确认与修改授权分别记录”只在管理帮助中说明，不重复压在正常阅读页上。

`claim_id`、`theorem_id` 和 `proof_id` 继续用于机器关联与稳定 URL，但不作为页面标题或读者主导航。必要时可以在“管理标识”中查看。公共 Lean 库仍有独立入口，可按数学概念和 API 查找；论文阅读不需要读者先理解这套实体模型。

原型只选了一篇正式 CVPR 2023 论文作示例，选择器明确说明这一范围。扩大收录范围应以本轮另行整理的论文清单和用户确认结果为依据，不能把当前示例数当作团队论文普查的结果。

## 5. 状态与计数文案

状态不合并成一个笼统的“已完成”。读者首先看到是否可读，然后看到原文对齐与验证范围；更多工程细节按需展开。

| 状态 | 普通中文说明 | 必须满足的依据 |
| --- | --- | --- |
| 待提取 | 材料已收录，原命题/原证明尚未提取 | 材料与位置真实存在 |
| 已提取待核对 | 已找到原文，还需核对陈述、证明和公式边界 | 原文片段与定位；不能自动宣布完整 |
| 尚未重写 | 已有原文，还没有中文重写证明 | 缺少权威中文正文或重写状态仍未开始 |
| 已重写 | 可在本页阅读中文证明 | 真实非空 `proof.zh.md` 与对应记录；不靠标签推断 |
| 原文已对齐 | 定义、假设、量词与结论已核对 | `alignment.yaml` 与来源证据 |
| Lean 尚未形式化 | 对应编码声明还未完成 | 没有已核验声明；不能借邻近公共结果完成标签 |
| Lean 已验证：公共定理 | 复用的公共声明有实际有效报告 | 成功构建、公理记录及当前指纹；论文对齐另验 |
| Lean 已验证：论文应用 | 论文适配声明有自己的有效报告 | claim 独立报告、实际声明及其源码指纹 |
| Lean 验证已过期 | 源码或依赖变化，需要重新验证 | 报告指纹与当前源不同 |
| 原证明未取得 | 原文只给结论或外引，证明材料未提供 | 来源缺口真实登记；不移出数学目标分母 |

统计至少分开“来源记录数”“经核对的独立数学目标数”“已有重写数”“原文已对齐数”“Lean 已验证数”。已认证清单才能计算数学目标覆盖率。历史 arXiv 试点 `denominator_reviewed: false`，18 条旧来源记录、3 条旧已核对出现对应 2 个数学结果；正式版本则尚未形成全篇清单，只显示本次对照的两个数学结果及正文/补充材料页数，不转用旧计数或显示覆盖率。尚未完成、原证明缺失和实际数学问题继续在正确的目标分母中；只有经过明确分类的引用、误报和重复出现不重复计目标。

1. **来源与状态契约。** 修复 `rewriting_status`/`rewrite_status`；区分提取提示与实际 issue 关联；增加原文本来源类型和命题/证明边界元数据。旧 `.tex` 文件不按扩展名自动升级为作者 TeX，原件不覆写。
2. **整理阅读目录。** 逐条核对引用误报与重复出现的分类，保留原记录与 `canonical_claim_id`；根据已核对关系建立原编号到阅读入口。历史投诉误报单独修订；正式版必须先按正文与官方补充材料建立清单，不能直接继承旧 arXiv 候选数量。不得借整理目录取消未完成目标。
3. **增加服务端阅读视图。** 将 paper、claim、所选 theorem/proof、真实 review/alignment、原文边界、依赖和 verification 组装成一次明确读取；公共模式继续使用现有隐私过滤。空字段决定紧凑的待完成提示，真实证明决定阅读正文。
4. **实现作者 TeX 阅读展示。** 限定已支持环境和宏，数学排版与原样源码使用同源内容；不支持部分原样保留，来源定位可返回。若只有 PDF，则另行核对转录，不伪造作者源码。HTML 安全处理与 KaTeX `trust: false` 继续保留。
5. **替换读者页，保留管理入口。** 首页/论文页按题名与章节编号导航；已重写默认中文正文，候选默认原文；共享、转换、技术报告折叠。原 claim 路由保留或明确指向规范阅读页，不能静默丢出处。
6. **完成必要回归。** 用正式版已完成真实条目、未完成真实条目、引用误报、经正式版定位的数学疑点、只有 PDF、private、公用证明更新与失效报告覆盖读模型契约；检查辅助 TeX 字节/复制与明确版本说明、版本定位、步骤往返、公开导出和窄屏。内容变动若影响数学映射，再由对应数学/Lean 验收处理。

不要先把页面做成全部“已完成”再补数据。正式实现完成的最低展示标准是：读者从论文目录进入一条已重写命题，能在原页读完已有中文证明并核对原来源；进入未完成项，能看懂缺少什么并返回原文；实际数学问题只显示自己的具体依据。完整论文质量和覆盖率仍按原计划逐项推进。
