# 阅读流程评估与第二阶段建议

本评估基于本机 Chromium 对当前已验收六篇数据的实际任务走查，记录见 `reader/evidence/twelve-paper-20261001/ui-workflow-evaluation.json`，截图与报告绑定该次公开快照 SHA-256。它是代理执行的任务评估，不是用户可用性研究；扩到十二篇后还会测量最终数据。第一阶段不据此重排布局，第二阶段须待根代理确认第一轮发布或明确授权切换。

## 实际任务路径与可核查问题

| 任务与目标 | 实际路径 | 已观察到的行为与影响 |
| --- | --- | --- |
| 长证明：读条件、检查一个 Lean 步骤并返回 | 首页 → Sparse 论文 → 导数截断结果 → 滚到末步骤 → Lean 对照 → 返回原步骤 | 进入结果需两次点击，完成 Lean 来回共四次。页面高 5,049 px，8 个步骤中出现 7 个同文案 Lean 按钮。论文条件、论文适配、共享条件与两次“证明思路”连续展开；读者须分别判断哪组条件属于当前论文、哪组属于公共命题。来回跳转能够定位步骤，应保留这一能力。 |
| 错误命题：分清反例、原错误与证据 | 首页 → CVPR → Dummy → 原证明 → 完整核验记录 | 两次点击进入结果时，顶部已明确“原命题有反例”。默认正文有反例，但精确原式问题卡片在第三次点击的原证明页，完整位置/影响记录在第四次点击。另测已修复的 Linearity 原证明：默认顶部显示完整证明与编译状态，进入原证明后才出现错误卡片。命题反例的可见状态应保留；证明修复记录也应在主阅读路径可发现。 |
| 公共证明：核对论文适配、公共条件和复用入口 | 重构结果 → 论文适配 → 同页公共证明 | 共 8 个步骤及 8 个 Lean 按钮，页面高 5,730 px。共享正文已经连续可读，但该页未显示指向独立公共证明页的链接；读者能读全文，却不容易从这条结果找到公共证明的稳定来源。 |
| 符号映射：辨认输入/输出基线并回到结果 | Generalizable AND/OR → 输出基线符号 → 已展开且按论文筛选的符号页 | 一次点击能定位正确规范符号并展开该论文映射，选中符号有当前结果的返回链接。符号查询会离开阅读页；返回是一次新导航，长证明读到哪里未在此流程中保留。 |

低频操作目前分散在原文页、Lean 面板、原公式转录、公共库说明与核验记录中。仅把按钮总数降低无法说明改善：应以读者完成上述任务所需的路径、条件归属、问题可见性与阅读位置连续性来验收。

## 精简且保留功能的方案

主阅读页按“结论 → 条件与规范符号 → 证明 → Lean 证据”组织。结论区域同时显示命题判断、证明范围与当前机器证据角色；证明错误、错误子句、定义域问题及无当前证据使用准确类别，给一句影响范围和直接核验入口，不放入折叠的低频菜单。全部真实前提在证明前可读，常见符号定义可按需展开；规范符号仍与原作者记号分别保存。

证明正文连续呈现，论文适配与共享正文有明确归属。公共证明标题附稳定入口及本篇使用的前提，正文只呈现一次；取消重复的段落标题时不删推导或条件。步骤依据在其实际需要的位置说明，正文已经解释的依据无需再复制一段“依据”。

语言切换和论文/结果导航继续常驻。原文对照收纳为一个清楚的入口，内部保留原陈述、作者原证明、正式页图和源 PDF；下载 TeX、JSON、完整报告、源代码等放在对应区域的“材料与下载”展开项。机器面板保留实际类型、作用范围、当前报告、公理与源码；主阅读区使用统一的 Lean 入口，步骤旁保留可用键盘到达的精简对应控件，并能返回同一步。

规范符号查询优先在当前阅读页展示定义、域、作用域、基线/空集与本篇原符号映射，保留前往完整符号表的入口。查看 Lean、原文或符号后返回须恢复原步骤和语言；移动端沿同一信息顺序显示，长公式只在公式容器内横向滚动。

第二阶段实施前由数学代理先完成十二篇的规范符号和共享依赖审查，界面只消费已核对的数据。验收沿用四条真实任务，增加新篇的条件性证明、部分反例与未形式化目标，逐一检查重要问题始终可发现、来源与下载仍能找到、语言及阅读位置保持、全部公式与机器证据当前。

## 本地性能基线

`reader/check_reading_performance.py` 对同一 Chromium 每种页面测量五次本地导航，报告在 `reading-performance.json`。本次中位数为：首页 163 ms、最大论文目录 148 ms、长证明 231 ms、全部符号页 676 ms；全库检索同步处理的最大耗时约 4.3 ms，长证明滚动最大帧间隔约 16.9 ms，能到页尾且无页面横向溢出。这些数字只说明当前机器的本地静态服务，不能预测远程网络或较慢设备。

公式使用仓库内的 KaTeX，保持 `trust:false`；真实浏览器禁止外部资源请求。全部符号页一次构造所有卡片并渲染折叠内容，现有符号页是较慢的阅读路径；十二篇最终数据测量后再决定是否按需渲染。第一阶段保留现有公式容器横向滚动、原页图 lazy loading 与独立证据，不因性能优化删数学内容。
