# 数学展示与 Lean 约定

模型记为 \(v:X\to\mathbb R\)，输入为 \(x\)，输入基线向量为 \(r\)。有限变量集为 \(N\)，保留 \(S\subseteq N\) 得到 \(x_S\)。集合函数、输出基线和中心化函数分别为

\[
g(S)=v(x_S),\qquad b=v(x_\varnothing),\qquad g_0(S)=g(S)-b.
\]

三者不能仅靠替换字母互换。论文原符号仍原样保留；例如 Sparse 的输入基线 \(b\) 对应规范向量 \(r\)，不是规范输出基线标量 \(b\)。完整定义、原页码、作用域及差异见 `research/full-proof-integration-20260930/data/full-content.json` 的 `symbols` 与阅读器符号表。

对任意集合函数 \(f\)，通用 Möbius 变换为

\[
I_f(S)=\sum_{T\subseteq S}(-1)^{|S|-|T|}f(T).
\]

原始交互 \(I_g\)、中心化交互 \(I_{g_0}\)、AND 分量交互及条件掩码游戏的交互是不同的作用域实例。空集满足 \(I_f(\varnothing)=f(\varnothing)\)；原始交互的空集值为 \(b\)，中心化交互的空集值为零。非空交互在中心化前后相同，空集不能沿用这个结论。Generalizable 的条件游戏使用掩码合成，不能默默把 \(I(S\mid x_T)\) 换成固定 \(x\) 的系数。

OR 交互也区分原始、中心化、OR 分量和条件游戏。非空集合按论文负号及补集定义计算，空集的特设基线单独保存。AND/OR 的相同字母不会自动合并为同一概念。噪声随机变量与可学习的确定性误差、交互阶数与样本数、输入基线与输出基线分别登记。

Lean 的 `Harsanyi.Game α` 使用 `Finset α → ℝ`。变量类型可以无限，所有参与求和的总体及集合仍有限；论文有限总体需要真实实例化。`DecidableEq` 是有限集表示所需的 Lean 实现条件，不是另加的数学假设。既有 Lean API 中形参可能仍名为 `v`，数学展示使用 \(g\)；不为统一展示改动库接口。
