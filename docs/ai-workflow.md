## 从已完成状态继续

1. 读取已有 manifest、inventory、claims、relations、catalog 和报告。先运行 validate、coverage、verify --report-only，分清文件存在与实际通过验证。
2. 选择一个未完成条目，写清目标、依赖、现有证据和下一步。不要重新启动全网普查，也不要把现有来源再下载到别处。
3. 检查材料隐私。手动未发表默认 private；不要向外部 AI、解析服务或搜索页发送文本。公开链接的查阅不授权上传本地私稿。
4. 先对齐定义和假设，再查 search-lemmas / show-lemma，优先复用公共库。相似匹配只作候选，核对证据写 relations。
5. 重写、形式化、审校分别更新状态。运行真实验证；失败保留日志，源码变更使旧报告过期。未完成项保持分母与待办。
6. 运行 build 和页面检索；检查源码/报告入口、共享双向链接以及 private继承。记录实际命令与结果，更新 STATUS。

使用库证明用户新结论时，直接走 ai-use-library，无需导入论文或启动 archive。扩展公共库读 library-contributing；不擅自修改既有接口前提。
